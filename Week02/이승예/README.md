# [전화번호 목록] 문제 접근 방법 정리
## 문제 파악
전화번호 목록 phone_book이 주어진다. <br>
목록에 있는 전화번호 중 어떤 번호가 다른 번호의 접두사(prefix) 인 경우 false를 반환하고, <br>
그렇지 않으면 true를 반환한다.

예시
- ["119", "97674223", "1195524421"] → false
- ["123", "456", "789"] → true

## 접근 방법
1. phone_book을 문자열 기준으로 정렬한다.

2. 정렬된 배열에서 인접한 두 번호만 비교한다.

3. 앞 번호가 뒤 번호의 접두사라면 즉시 false를 반환한다.

4. 모든 비교를 통과하면 true를 반환한다.
